# West Bengal Agro-Climatic Crop Yield Dataset

Dataset accompanying the paper *"Generative AI for Precision Agriculture: A Conditional
GAN and Random Forest Framework for Climate-Resilient Crop Yield Forecasting and
Risk-Aware Decision Support"* (Subrata Mapa, Abhijit Paul, Apratim Mitra).

## What this is

`engineered_agriculture_dataset.csv` contains 18,225 station-crop-year records covering:

- **23 districts** of West Bengal, India, grouped into **6 real agro-climatic zones**
  (Hill Zone, Terai-Teesta Alluvial, Old Alluvial, New Alluvial, Red & Laterite, Coastal Saline)
- **81 stations** (3–4 per district)
- **9 crops**: Rice, Wheat, Maize, Pulses, Millet, Jute, Potato, Sugarcane, Mustard
- **25 years** (2000–2024)
